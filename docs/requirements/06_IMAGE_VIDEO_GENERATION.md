# IMAGE + VIDEO GENERATION

## Unified-first rule

If the configured Unified Gateway provides image/video generation, use it.

If not:
allow optional dedicated provider configuration.

## Image generation UI
- Prompt
- Aspect Ratio
- Quality
- Count
- Style
- Generate
- Progress
- Cancel
- Retry
- Preview
- History
- Download
- Share

## Video generation UI
- Prompt
- Optional image reference
- Aspect Ratio
- Duration
- Quality
- Generate
- Job status
- Progress
- Cancel where supported
- Retry
- Preview
- Download
- Share

Video generation must be asynchronous.

Never fake a completed generation.
