# FREE-ONLY / PRIVACY REQUIREMENTS

This product is for one owner and optionally a few friends/family.

It is NOT a public SaaS service.

Rules:
- no mandatory paid backend
- no mandatory paid database
- no mandatory paid auth
- no mandatory paid storage
- no subscription required
- user supplies their own API key(s)
- do not automatically activate billing
- prefer free/open-source/on-device features

Each installation must be independent.

The owner's credentials must not be shared with another APK installation.

Default chat history should remain local on-device.

Optional sync can be added later but must be disabled by default.
