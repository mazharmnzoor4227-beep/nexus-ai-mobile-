# VOICE REQUIREMENTS

## Voice typing

- microphone button
- STT
- editable transcript
- Urdu
- Hindi
- English
- language auto detection where possible

## Full voice conversation

Use the Stitch full-screen voice layout as reference.

States:
- Listening
- Processing
- Thinking
- Speaking
- Reconnecting

Required:
- VAD
- STT
- LLM streaming
- TTS
- interrupt speaking
- mute
- speaker toggle
- end call
- transcript
- reconnect

Optimize latency.

If cloud STT/TTS is unavailable, support Android/system or local alternatives where
practical.
